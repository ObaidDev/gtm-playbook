# Workflow skills hand their Interview to one shared skill

Every workflow skill runs the same Interview loop, copied from an outside skill under the MIT License. Instead of quoting that loop verbatim in each workflow skill (each with its own NOTICE.md), the loop lives once in `skills/meta/interview/`, beside the only NOTICE.md, and each workflow skill calls it through the Skill tool. The workflow skill keeps everything specific to its Profile section: what to explore, its root branches and their done-when tests, and its confirm-before-write rule. We chose this over the verbatim copies because five identical blocks drift and bury the part of each skill that matters (what to ask the Founder), and over a shared Markdown file linked by path because a skill matches the pattern of the skill it was copied from and can be reused by later skills by name. The cost is that `interview` must be model-invocable, so it is hidden from the `/` menu (`user-invocable: false`) and its description says to run it only when a gtm-playbook skill says so.
